# F06-007 — Finish / Species Variant Images

## Feature Specification

| Field | Value |
|-------|-------|
| Feature ID | F06-007 |
| Feature Name | Finish / Species Variant Images |
| Module | 06 — AI Product Imagery |
| Module Type | Technical |
| Release | Optional |

### Description
Optional variant images per product for its main finishes or species (for example primed, poplar, oak), generated from the approved base render, with a finish switcher on the product page.

### Business Objective
Let visitors see how a profile looks in different finishes.

### Actors
- Delivery imagery specialist
- Visitor

### User Journey
1. **Who creates:** Variants are generated by the imagery specialist from approved base renders.
2. **How they create:** Visitors switch finishes on the product page.
3. **How they edit:** Variants are regenerated if needed.
4. **How they send for approval:** No in-system approval applies; output is verified through the Garrison review workbook (F04-004) and user acceptance testing (F05-005).
5. **How the approver sees pending items:** Not applicable for visitors; there is no approver inbox.
6. **How the approver decides:** No approval decision applies on public pages.
7. **How the maker sees history:** Not applicable for visitors.
8. **How the approver / auditor sees history:** Garrison approves the pages on staging during user acceptance testing (F05-005).

### Functional Capabilities
- Variant generation per finish
- Finish switcher

### UI Screens
- Finish switcher on product detail

### Logical API Operations
- Generate finish variants from approved base render
- Attach variants to product data

### Inputs
- Approved base renders
- Finish list

### Outputs
- Variant images

### Business Rules
- Variants use the same geometry as the approved image

### Validations
- Variant exists for each listed finish or the switcher hides it

### Calculations
- None

### Workflow
Not applicable

### Search Requirements
- None

### Documents
- None

### Reports
- None

### Notifications
- None

### Security
- Site-wide controls apply: HTTPS, escaped inputs, no admin login surface

### Integrations
- None

### Dependencies
- F06-003
- F03-003

### Assumptions
- Up to 3 finishes per product; variant review time and AI cost charged per variant

### Risks
- Wood grain realism varies by finish

### Non Functional Requirements
- Switching finishes is instant
