# F09-004 — Search Suggestions & Results Experience

## Feature Specification

| Field | Value |
|-------|-------|

| Feature Name | Search Suggestions & Results Experience |
| Module | 09 — Search & Filtering |
| Module Type | Business |
| Release | Go-live |

### Description
Type-ahead suggestions grouped by product codes, products, categories and combinations; results page sort and view options; mobile full-screen search overlay; no-results page with suggestions, popular searches and an enquiry prompt.

### Business Objective
Shorten the path to the right profile and recover gracefully when a search finds nothing.

### Actors
- Visitor

### User Journey
1. **Who creates:** Visitors create queries; suggestions are generated by the system.
2. **How they create:** As visitors type (after 2 characters), suggestions appear; selecting one opens the product or category directly.
3. **How they edit:** Visitors refine the query; suggestions update.
4. **How they send for approval:** No approval applies.
5. **How the approver sees pending items:** There is no approver inbox.
6. **How the approver decides:** No decision applies.
7. **How the maker sees history:** Visitors see recent searches stored in their own browser.
8. **How the approver / auditor sees history:** Not applicable for auditors; aggregate search behaviour is reported in F11-004.

### Functional Capabilities
- Debounced type-ahead with grouped suggestions and thumbnails
- Keyboard navigation of suggestions
- Results sort (relevance, code, name) and grid/list toggle
- Mobile search overlay
- No-results page with spelling fallback, popular searches and Request Information prompt

### UI Screens
- Type-ahead suggestions dropdown
- No-results page with suggestions
- Results sort and view toggle
- Mobile search overlay

### Logical API Operations
- Get grouped search suggestions
- Get fallback suggestions for no results
- Get popular searches

### Inputs
- Partial query text

### Outputs
- Suggestions, results views, fallback suggestions

### Business Rules
- Suggestions only from Published content
- Maximum 8 suggestions per group

### Validations
- Minimum 2 characters before suggesting

### Calculations
- Popular searches from last 30 days

Not applicable
