# F03-004 — Project History & Search

## Section 1 — Feature Specification

| Field | Value |
|---|---|
| **Feature ID** | F03-004 |
| **Feature Name** | Project History & Search |
| **Module** | 03 — Housing Project Management |

### Description
Provide project-level search, history, and audit-oriented retrieval across creation, changes, approval, and publication.

### Business Objective
Give authorised users a reliable project trace for operations and audit.

### Actors
Engineering Section; Approvers; Auditor; management viewers.

### User Journey
User filters the Project Register, opens a project timeline, reviews change/approval/publication events, and exports results.

### Functional Capabilities
Advanced search; project timeline; status/approval history; activity detail; filtered export.

### Inputs
Project reference, event metadata, filters, date range.

### Outputs
Project history view and exportable results.

### Business Rules
History is read-only; business changes are captured at source; access follows role permissions.

### Validations
Valid date range; restricted events shown only to permitted roles.

### Calculations
None.

### Workflow
Project event occurs in owning feature → timeline records it → authorised user retrieves/export.

### Search Requirements
Code/name, layout, zone, status, approver, event type, date range.

### Documents
Linked project document history is surfaced from F03-002.

### Reports
Project History and Activity Register.

### Notifications
None beyond events generated by owning project processes.

### Security
Read-only access; audit of history export.

### Integrations
None.

### Dependencies
F03-001 through F03-003; Module 01 audit controls.

### Assumptions
This is project-specific history, not a global reporting module.

### Risks
Overly broad filters may affect response time at scale.

### Non Functional Requirements
Fast filtered retrieval; chronological integrity.
